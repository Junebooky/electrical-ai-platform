## 단계별 계획

### MVP 1 (현재 단계 - 완료)
- [x] 모노레포 구축 (`apps/web`, `apps/api`, `packages/cad_engine`)
- [x] ezdxf 기반 결정론적 DXF 파서 및 정규화 스키마 (v0.1.0)
- [x] 안전한 로더 (DWG 거부, 트렁케이션 방어, 크기 제한, 복구 파싱)
- [x] 14종 합성 DXF fixture 및 기대값 검증 자동 회귀 테스트 (15 passed)
- [x] 2D SVG 인터랙티브 CAD 뷰어 (줌/팬/레이어/하이라이트/선택)
- [x] 기호-품목 매핑 및 실시간 반자동 물량산출
- [x] 오탐 제외/복원 검수 및 누락 기구 수동 추가
- [x] CSV(UTF-8-SIG) 및 XLSX(멀티시트) 내보내기
- [x] 로컬 데이터 영속화 및 재열기 복원
