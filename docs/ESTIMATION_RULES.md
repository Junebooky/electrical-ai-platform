# Electrical Estimation Rules & Domain Constraints

- **문서 ID:** EAI-EST-001
- **기준:** PRD §5, §6, DEC-002
- **도메인 책임:** A05 Electrical Domain Agent 협업 기준

---

## 1. P0 기본 적산 정책 (기구 수량 집계)

MVP 1은 **조명·콘센트·스위치 등 전기기구 수량의 반자동 산출**에 집중합니다.

1. **블록 매핑 우선 (DEC-002)**:
   - 블록명만으로 실제 기종·규격을 자동 확정하지 않습니다.
   - 프로젝트별로 사용자가 지정한 `ItemMappingRule`에 부합하는 객체만 해당 품목으로 집계합니다.
2. **최상위 INSERT 집계**:
   - Model Space 최상위(`depth == 0`)의 INSERT 객체만 기본 집계 대상(`INCLUDED`)으로 처리합니다.
3. **배열 삽입(MINSERT) 전개**:
   - MINSERT 블록은 행(row) × 열(col) 개수만큼 가상 엔티티로 펼쳐서 개별 객체로 집계합니다.
4. **산출 방식(Quantity Method) 명시**:
   - `CAD_BLOCK`: CAD 블록 파싱을 통해 자동 집계된 수량
   - `MANUAL`: 사용자가 직접 도면에 좌표를 찍어 추가한 수량
   - `MIXED`: 동일 품목 내 CAD 블록과 수동 추가가 혼합된 경우

---

## 2. P0에서 산출하지 않는 항목 및 경고

1. **배선 / 전선관 길이 자동 산출 금지**:
   - CAD 도면의 LINE / LWPOLYLINE 길이는 도면상의 기하학적 치수일 뿐, 천장 은폐 배선, 입상·입하(수직 배선), 여장 길이, 굴곡률을 반영하지 않습니다.
   - 따라서 P0에서는 도면의 선 길이를 실제 케이블 포설 길이로 산출하지 않습니다.
2. **중첩 블록(Nested Blocks)**:
   - 한 블록 내부에 다른 기구 블록이 삽입되어 있는 경우, 이중 집계(Double Counting) 위험이 있으므로 A05의 규칙 검토 전까지 기본적으로 `UNRESOLVED` 사유로 분리합니다.
3. **꺼짐 / 동결 레이어 객체**:
   - 숨김 처리된 레이어의 기구는 시공 제외 대상일 가능성이 높으므로 자동 집계하지 않고 `UNRESOLVED` 상태로 표시합니다.

## 3. A05 검토 요청 사항 (EAI-E001)

- [ ] 국내 표준 전기설계 심볼 라이브러리 (KS C 0301) 표준 블록명 및 범례 체계화
- [ ] 중첩 블록 집계 규칙 (그룹 기구 분해 기준)
- [ ] 전선관·케이블 산출을 위한 입상/입하 및 여장 배율 공식
- [ ] 표준품셈 노무비 연계 품목 코드 분류체계
